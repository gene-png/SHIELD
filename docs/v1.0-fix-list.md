# SHIELD v1.0 fix list — completion of `feat/v0.1-spine`

This document is the canonical work plan from `feat/v0.1-spine` (~30%
complete scaffold) to v1.0 (spec-complete per
[unified-portal-spec.md](unified-portal-spec.md)). Each item is a
discrete change; each milestone is one PR.

Status snapshot (as of branch `feat/v0.1-spine` commit `1da86d6`):

- Stack boots clean on Postgres 16 + Keycloak 25 + Flask app.
- Migration + seed work; 12 tables, Acme Co + 79 capability items, 3
  projects, 3 demo users.
- Identity / repository / picker / audit / clients spine modules are
  implemented. Origin immutability is enforced in code (SQLAlchemy event
  listener) and DB (Postgres trigger). Picker rejects AI-origin selection
  without explicit acknowledgment.
- AI client supports `real` + `fixture` modes; per-platform prompts and
  fixtures exist.
- All three platform routes are wired and call the AI client. Repository
  browser exists.
